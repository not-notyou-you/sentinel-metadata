ℹ️ Tentang Citra SAR Sentinel-1

  • VV (vertikan-vertikal): cocok untuk deteksi banjir, area tergenang tampak gelap
  • VH (vertikal-horizontal): lebih sensitif terhadap vegetasi dan struktur kota
  • Kontras di-stretch otomatis (percentile 2–98%) untuk memudahkan visualisasi
  • Warna gelap = backscatter rendah (air/banjir). Warna terang = backscatter tinggi (kota/gedung)

💡 Tips Hemat Storage (konfigurasi di config/config.json)

  • Mode minimal: keep_raw=false + keep_bronze=false + keep_silver=false → simpan GOLD saja (~40 MB/scene/band)
  • Mode standar: keep_raw=false + keep_bronze=true + keep_silver=true → ~130 MB/scene/band
  • Mode lengkap: semua true → ~870 MB/scene/band (termasuk ZIP asli ~800 MB)
  • Satu scene Sentinel-1 IW GRD ≈ 800 MB raw. Setelah crop Jabodetabek → ±50 MB per band.
